# cauchyjia.github.io

Minimalist personal homepage hosted on GitHub Pages: https://cauchyjia.github.io

## Structure

- `index.html` — Main page content (About, Research Interests, Publications, and commented templates for News / links)
- `style.css` — Clean typography, responsive layout, light/dark mode styles
- `.nojekyll` — Serve static files directly on GitHub Pages

## Update

Edit `index.html` or `style.css`, then push to `main`:

```bash
git add .
git commit -m "Update homepage"
git push
```
